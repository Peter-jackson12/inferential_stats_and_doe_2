# inferential_stats_and_doe_2

추론통계 및 실험계획법 수업 실습/과제 노트북 저장소입니다.

## 실행에 필요한 데이터

원본 데이터 파일은 저장소에 포함하지 않고 `data/` 폴더에서 로드하도록 구성되어 있습니다.

- `data/ames_housing.csv`
- `data/cookie_cats.csv`

수업에서 제공된 원본 CSV를 위 경로에 배치한 뒤 저장소 루트에서 Jupyter Notebook을 실행하면 됩니다. 일부 노트북은 호환성을 위해 노트북과 같은 폴더의 CSV도 탐색합니다.

## 주요 노트북

- 1장: 가설검정, 유의수준·검정력, 검정 방법 선택
- 2장: t검정, ANOVA와 사후검정
- 3장: 카이제곱 독립성검정, 피어슨 상관
- 4장: 단순선형회귀
- 5장: A/B 테스트 설계, 검정력과 MDE 기반 표본 설계

노트북에는 실행 결과가 저장되어 있으나, 재실행하려면 위 원본 데이터 파일이 필요합니다.
